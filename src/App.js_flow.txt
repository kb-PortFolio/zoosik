1. useEffect <Auth 리스너>

- onAuthStateChanged로 로그인/로그아웃 상태 감지
- 로그인 시 fbUser(Auth 사용자 정보) 전달
- onSnapshot으로 users/{uid} 문서를 실시간 구독
- 문서가 변경되면 setUser()로 React user state 갱신
- 로그아웃 시 setUser(null)

------------------------------------------------

2. useEffect <prices 초기화>

- user.uid가 생기면 ensureUserPrices() 실행
- prices 컬렉션이 없으면 생성
- 기존 유저면 아무 작업 없이 return

------------------------------------------------

3. useEffect <최신 stocks 유지>

- stocks가 변경될 때마다
  current_stocks.current를 최신 stocks로 갱신
- setInterval에서 항상 최신 stocks를 사용하기 위한 useRef 동기화

------------------------------------------------

4. useEffect <20초마다 가격 저장>

- 로그인 상태(user.uid)에서만 실행
- 20초마다 current_stocks.current(최신 stocks)를 Firestore에 저장
- 로그아웃/컴포넌트 종료 시 Interval 제거(clearInterval)

------------------------------------------------

5. useEffect <가격 불러오기>

- user.uid가 생기고 pricesInitialized가 true가 되면 실행
- Firestore prices 컬렉션에서 현재 가격 조회
- priceMap 객체로 가공 후 이전 종가(prevClose)와 합쳐 stocks 형태로 변환
- setStocks()로 React stocks state 갱신

------------------------------------------------

6. useEffect <주식 가격 갱신>

- user.uid가 있으면 실행
- 최초 1회 updatePrices() 실행
- 이후 1초마다 updatePrices() 실행(setInterval)
- 로그아웃/컴포넌트 종료 시 Interval 제거(clearInterval)
